# claud3 3단계(Ink TUI) Implementation Plan

> **agentic worker에게:** REQUIRED SUB-SKILL: 이 plan을 task 단위로 구현하려면 suberpower:subagent-driven-development(권장) 또는 suberpower:executing-plans를 사용하세요. Step은 추적을 위해 checkbox(`- [ ]`) 문법을 사용합니다.

**Goal:** 같은 `Session`과 `UiEvent`를 쓰는 Ink 화면을 기본 UI로 추가하고, `--plain`으로 기존 readline 화면을 유지한다.

**Architecture:** 화면 상태는 순수 함수 `reduceTranscript(state, event)`가 `UiEvent`로부터 만든다. Ink 컴포넌트(`App`, `Transcript`, `InputBox`, `PermissionDialog`, `StatusBar`)는 그 상태를 그리기만 한다. 권한 요청은 `PermissionPrompter`가 상태에 대기 요청을 넣고, `PermissionDialog`의 선택으로 resolve한다. 2단계의 `commands`·`usageStore`·`MultilineBuffer`는 그대로 재사용한다.

**Tech Stack:** 2단계 + `ink`, `react`, `@types/react`, `ink-testing-library` (작성 시점의 최신 안정판. 설치 후 `ink`의 `render`, `Static`, `useInput`, `Box`, `Text` API를 문서로 확인)

**Spec:** `docs/suberpowers/specs/2026-10-21-claud3-design.md` (6절 3단계)

## Global Constraints

- 1·2단계 Global Constraints를 따른다.
- `tsconfig.json`에 `"jsx": "react-jsx"`를 추가하고 컴포넌트는 `src/ui/ink/*.tsx`에 둔다.
- `--plain`이면 `ui/plain`, 아니면 Ink UI. stdin이 TTY가 아니면 자동으로 `ui/plain`.
- 완료된 대화 항목은 Ink `Static`으로 그려 스크롤 성능을 유지한다. 진행 중인 응답만 동적으로 그린다.
- 키: Esc·Ctrl+C·Ctrl+D 동작은 1단계 `ui/plain`과 같다.

## Review Focus

1. 터미널 폭이 매우 좁음(40칸) → 줄바꿈되어도 깨지지 않고 상태 줄이 한 줄을 넘으면 잘린다.
2. 응답 스트리밍 중 권한 요청 → 진행 중 텍스트를 확정(Static으로 이동)한 뒤 대화상자를 띄운다.
3. 권한 대화상자에서 Esc → 거부(deny)로 처리한다.
4. 매우 긴 단일 응답(수천 줄) → 입력창이 화면 밖으로 밀려나지 않는다.
5. 한국어 등 전각 문자 입력·커서 이동 → 입력창 표시 폭이 어긋나지 않는다.

### Task 1: 대화 상태 리듀서 (`ui/ink/transcript.ts`)

**Files:** Create `src/ui/ink/transcript.ts`, Test `test/ink-transcript.test.ts`

**Interfaces:**
- Produces:
  ```ts
  export type TranscriptItem =
    | { kind: "user"; id: number; text: string }
    | { kind: "assistant"; id: number; text: string }
    | { kind: "tool"; id: number; toolUseId: string; name: string; summary: string; status: "running" | "done" | "error"; errorSummary?: string }
    | { kind: "notice"; id: number; tone: "info" | "error"; text: string };
  export interface TranscriptState {
    done: TranscriptItem[];                                  // Static으로 그리는 확정 항목
    running: (TranscriptItem & { kind: "tool" })[];          // 실행 중인 도구
    streaming?: TranscriptItem & { kind: "assistant" };      // 진행 중인 응답
    nextId: number;
    sessionCostUsd: number;
    model?: string;
    header?: string;
  }
  export const initialTranscript: TranscriptState;
  export function addUserInput(state: TranscriptState, text: string): TranscriptState;
  export function addNotice(state: TranscriptState, tone: "info" | "error", text: string): TranscriptState;
  export function reduceTranscript(state: TranscriptState, event: UiEvent): TranscriptState;
  ```
- 규칙: `text_delta`는 `streaming`에 이어 붙임. `tool_start`·`turn_result`·`error`·권한 대기 진입 시 `streaming`을 `done`으로 확정. `tool_start`는 `running`에 추가하고, `tool_end`는 같은 `toolUseId` 항목의 status를 바꿔 `running`에서 `done`으로 옮긴다(Static에 들어간 항목은 다시 그려지지 않기 때문). `turn_result`는 비용 갱신과 오류 notice. `session_start`는 `header`·`model` 설정.

- [ ] **Step 2: 실패 확인** — `npx vitest run test/ink-transcript.test.ts` → FAIL
- [ ] **Step 3: 구현**
- [ ] **Step 4: 통과 확인** — `npx vitest run test/ink-transcript.test.ts && npm run typecheck` → PASS

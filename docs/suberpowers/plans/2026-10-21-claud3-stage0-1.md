# claud3 0·1단계 Implementation Plan

> **agentic worker에게:** REQUIRED SUB-SKILL: 이 plan을 task 단위로 구현하려면 suberpower:subagent-driven-development(권장) 또는 suberpower:executing-plans를 사용하세요. Step은 추적을 위해 checkbox(`- [ ]`) 문법을 사용합니다.

**Goal:** 프로모션 API 크레딧으로 과금되는 Agent SDK 기반 터미널 CLI `claud3`의 최소 버전(1단계)을 만들고, 이후 `claud3`가 스스로를 개발할 수 있는 안정판·개발판 체계를 갖춘다.

**Architecture:** 하나의 `query()`를 streaming input mode로 유지하는 `Session`이 SDK 메시지를 `UiEvent`로 바꿔 내보내고, `ui/plain`은 이벤트를 그리고 입력과 권한 응답만 돌려준다. 인증·설정은 `auth`·`config`가 만들어 `Session`에 주입한다. 전역 `claud3` 명령은 git 태그로 고정한 안정판 worktree를 가리킨다.

**Tech Stack:** Node 24, TypeScript(ESM, `tsc` 빌드), `@anthropic-ai/claude-agent-sdk`, `tsx`(개발 실행), `vitest`, `node:readline`, `node:util`의 `styleText`(색상, 추가 의존성 없음)

**Spec:** `docs/suberpowers/specs/2026-10-21-claud3-design.md`

## Global Constraints

- API 키는 macOS 키체인 서비스 `anthropic-api`에서만 읽고, SDK 하위 프로세스 `env`의 `ANTHROPIC_API_KEY`로만 넘긴다. 파일·로그·화면에 출력하지 않는다.
- SDK 옵션: `settingSources: ["user", "project", "local"]`, `systemPrompt: { type: "preset", preset: "claude_code" }`, `includePartialMessages: true`
- 자동 테스트는 실제 API를 호출하지 않는다. 실제 호출은 Task 1(확인용)과 Task 7·8(수동 확인)에서만 한다.
- `any` 타입을 쓰지 않는다. SDK 타입은 `@anthropic-ai/claude-agent-sdk`에서 import한다.
- 사용자에게 보이는 문구는 한국어로 쓴다.
- 전역 명령 이름 `claud3`, 안정판 worktree 경로 `~/.local/share/claud3/stable`, 태그 형식 `stable-N`(N은 1부터)
- 커밋 메시지 끝에 다음 두 줄을 붙인다.
  ```
  Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_017o9psuu92MmJdNaa7x4Yky
  ```

## Review Focus

1. 권한 질문 중 Ctrl+C → 해당 도구를 거부하고 턴을 중단하며, 프로그램은 종료되지 않는다.
2. `installed_plugins.json`이나 `settings.json`이 없거나 JSON이 깨졌거나, 플러그인 `installPath`가 삭제됨 → 그 플러그인만 건너뛰고 시작은 계속된다.
3. 턴 실행 중 사용자가 다음 줄을 입력 → 버리지 않고 대기열에 넣어 현재 턴이 끝난 뒤 보낸다.
4. 빈 줄이나 공백만 있는 입력 → SDK로 보내지 않는다.
5. 대기 중(턴 없음) Esc 또는 Ctrl+C 한 번 → 아무 일도 일어나지 않거나 종료 안내만 표시한다. SDK `interrupt()`를 부르지 않는다.

### Task 6: 세션 (`session`)

**Files:**
- Create: `src/session.ts`
- Test: `test/session.test.ts`

**Interfaces:**
- Consumes: `createEventMapper`, `summarizeToolInput` (Task 2), `UiEvent`, `PermissionPrompter` (Task 2), `AsyncQueue` (Task 5)
- Produces:
  ```ts
  export type QueryFn = (params: { prompt: AsyncIterable<SDKUserMessage>; options: Options }) => Query;
  export interface SessionDeps {
    queryFn: QueryFn;
    baseOptions: Options;
    prompter: PermissionPrompter;
    resume?: string;
  }
  export class Session {
    constructor(deps: SessionDeps);
    onEvent(listener: (event: UiEvent) => void): void;
    start(): void;              // query()를 열고 메시지 처리 루프를 백그라운드로 시작
    send(text: string): void;   // 공백만 있으면 무시
    get isBusy(): boolean;      // send 후 turn_result 전까지 true
    interrupt(): Promise<void>; // isBusy일 때만 query.interrupt()
    close(): Promise<void>;     // 대기열 닫고 session_closed 발행
    get sessionId(): string | undefined;
    get totalCostUsd(): number;
  }
  ```

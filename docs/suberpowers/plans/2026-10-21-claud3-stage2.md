# claud3 2단계(편의 기능) Implementation Plan

> **agentic worker에게:** REQUIRED SUB-SKILL: 이 plan을 task 단위로 구현하려면 suberpower:subagent-driven-development(권장) 또는 suberpower:executing-plans를 사용하세요. Step은 추적을 위해 checkbox(`- [ ]`) 문법을 사용합니다.

**Goal:** 1단계 CLI에 자체 슬래시 명령, 크레딧 추정 상태 줄, 여러 줄 입력, 실행 간 입력 기록, diff·마크다운 출력 스타일링, 사용자 도움말과 README를 더한다.

**Architecture:** 입력은 `commands.parseInput`이 먼저 보고 claud3 명령이면 `CommandContext`로 처리하고, 아니면 `session.send`로 넘긴다. 사용량은 `usageStore`가 `~/.config/claud3/usage.json`에 누적한다. 출력 스타일링은 화면과 무관한 순수 모듈(`diffView`, `markdown`)이 문자열을 만들고 `ui/plain`이 출력한다(3단계 Ink에서 재사용). `Session`에는 모델 변경·목록 조회와 세션 교체를 더한다.

**Tech Stack:** 1단계 + `diff`(jsdiff, 줄 단위 diff 계산. 9.x는 타입 포함)

**Spec:** `docs/suberpowers/specs/2026-10-21-claud3-design.md` (6절 2단계, 4절 데이터 흐름)

## Global Constraints

- 1단계 Global Constraints(`docs/suberpowers/plans/2026-10-21-claud3-stage0-1.md`)를 그대로 따른다. 자동 테스트에서 실제 API 호출 금지, `any` 금지, 사용자 문구는 한국어.
- 개발 중 확인은 `npm run dev`로 한다. 전역 `claud3`(안정판)는 사용자 요청이 있을 때만 `npm run promote`로 갱신한다.
- 작업은 `origin/main`에서 `--no-track`으로 만든 새 브랜치에서 한다. push는 `git push -u origin <브랜치명>`.
- 시작 잔액 기본값 US$100. 사용량 파일 `~/.config/claud3/usage.json`, 입력 기록 파일 `~/.config/claud3/history`(최대 500줄). 두 경로 모두 `CLAUD3_CONFIG_DIR` 환경변수로 바꿀 수 있다(테스트용).
- claud3 자체 명령: `/cost`, `/clear`, `/model [name]`, `/resume <id>`, `/help`. 그 밖의 `/`로 시작하는 입력(플러그인 스킬 `/suberpower:...` 등)은 SDK로 넘긴다.
- 색상은 `node:util`의 `styleText`만 쓴다(추가 색상 라이브러리 없음). 추가 의존성은 `diff` 하나.

## Review Focus

1. `usage.json`이 없거나 깨짐 → 기본값(시작 잔액 100, 사용 0)으로 시작하고, 다음 기록 때 정상 파일로 덮어쓴다.
2. 턴 실행 중 `/model <name>`, `/clear`, `/resume` → 실행하지 않고 "턴이 끝난 뒤 다시 입력해 주세요"를 표시한다. `/cost`, `/help`, 인자 없는 `/model`(목록 보기)은 실행 중에도 된다.
3. 매우 큰 Write(수천 줄)나 긴 Edit → diff는 최대 40줄만 보이고 `… N줄 더`로 줄인다. 화면이 밀려 권한 질문이 안 보이는 일이 없다.
4. 스트리밍 중 한 줄이 여러 `text_delta`로 쪼개져 오거나, 코드 블록 ``` 가 턴 끝까지 닫히지 않음 → 렌더링이 깨지거나 글자가 사라지지 않는다. 턴이 끝나면 남은 내용을 모두 출력하고 코드 블록 상태를 초기화한다.
5. 여러 줄 입력 중 Ctrl+C → 모아 둔 줄을 버리고 새 프롬프트를 띄운다.

### Task 3: 슬래시 명령 (`commands`)

**Files:** Create `src/commands.ts`, Test `test/commands.test.ts`

**Interfaces:**
- Consumes: Task 1 `readUsage`·`remainingCreditUsd`, Task 2 `Session.setModel`·`listModels`·`replace`·`currentModel`
- Produces:
  ```ts
  export type ParsedInput =
    | { kind: "command"; name: "cost" | "clear" | "model" | "resume" | "help"; argument: string }
    | { kind: "prompt"; text: string };
  export function parseInput(line: string): ParsedInput; // 앞뒤 공백 제거 후 판정, 이름은 대소문자 구분
  export interface CommandContext {
    session: Pick<Session, "isBusy" | "totalCostUsd" | "currentModel" | "sessionId" | "setModel" | "listModels" | "replace">;
    readUsage: () => Promise<UsageSnapshot>;
    print: (text: string) => void;
  }
  export const HELP_TEXT: string;
  export async function runCommand(command: Extract<ParsedInput, { kind: "command" }>, context: CommandContext): Promise<void>;
  ```
- 출력 문구:
  - `/cost`: `세션 $<4자리> · 전체 누적 $<spent 4자리> · 남은 크레딧 추정 $<remaining 2자리> (정확한 값은 Console)`
  - `/clear`: `새 대화를 시작했습니다`
  - `/model x`: `모델을 x(으)로 바꿨습니다`
  - `/model`(인자 없음): 첫 줄 `현재 모델: <currentModel ?? 기본값>`, 이어서 `listModels()` 결과를 한 줄씩 `  <value>  <displayName> — <description>`(현재 모델이면 앞에 `*`), 마지막 줄 `바꾸려면: /model <ID>`. `listModels`가 실패하면 `모델 목록을 가져오지 못했습니다: <message>`와 마지막 줄만 출력.
  - `/resume id`: `세션 <id>(으)로 이동했습니다`; 인자 없음: `사용법: /resume <session-id>  (현재 세션: <sessionId ?? 없음>)`
  - busy 중 `/model x`·`/clear`·`/resume`: `턴이 끝난 뒤 다시 입력해 주세요`
  - `/help`: `HELP_TEXT` 그대로. 내용은 아래 네 묶음:
    ```
    명령
      /cost            이번 세션 비용, 전체 누적 비용, 남은 크레딧 추정
      /model           현재 모델과 쓸 수 있는 모델 목록

      /clear           새 대화 시작
      /resume <ID>     이전 세션으로 이동 (종료할 때 세션 ID가 출력됩니다)
      /help            이 도움말
      그 밖의 /…       플러그인 스킬 등으로 Claude에게 그대로 전달 (예: /suberpower:brainstorming)
    키
      Enter            보내기 · 줄 끝에 \ 를 붙이고 Enter: 여러 줄 입력
      ↑/↓              이전 입력
      Esc / Ctrl+C     실행 중인 턴 중단 · 권한 질문 중 Ctrl+C는 거부
      Ctrl+C 두 번     종료 · Ctrl+D 종료
    권한 질문
      y 이번만 허용 · n 거부 · a 이 도구는 세션 동안 항상 허용
    실행 옵션 (터미널에서)
      claud3 --model <ID>      모델 지정해 시작
      claud3 --resume <ID>     세션 이어서 시작
      claud3 --help · --version
    ```

### Task 6: 화면 연결 — 명령, 상태 줄, 여러 줄 입력, 입력 기록, 스타일링

**Files:** Modify `src/ui/plain.ts`, `src/main.ts`, `test/ui-plain.test.ts`

**Interfaces:**
- Consumes: Task 1, 3, 4, 5
- Produces:
  - `export function formatStatusLine(params: { model?: string; sessionCostUsd: number; remainingCreditUsd: number }): string` → `<model ?? 기본 모델> · 세션 $<4자리> · 크레딧 잔여 추정 $<2자리>` (흐린 색)

화면 동작:
- `line` → `MultilineBuffer.push` → 완성된 입력이면 `parseInput` → command면 `runCommand`, prompt면 `session.send`.
